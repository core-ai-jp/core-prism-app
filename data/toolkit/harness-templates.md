# CORE AI Toolkit 実装テンプレート v1.0
社内の営利業務で編集・利用可能。資料本体の再販売・無断再配布不可。成果・法令適合の保証ではありません。

## ハーネス設計図
入力 → 検証 → 下書き → 人の承認 → 実行 → 結果照合 → 記録
失敗 → 停止 → 状態照合 → 担当者判断 → 復旧
各工程: 担当者 / 正本 / 許可ツール / 上限 / 失敗時の戻り先

## AGENTS.md 最小テンプレート
```markdown
# Project map
- 目的と受入条件: docs/PRD.md
- 設計とデータ正本: docs/ARCHITECTURE.md
- 検証: 実在するコマンドを記入
- 環境: 開発 / 検証 / 本番を明示
- 変更禁止: 既存契約・他作業者の差分・権限外データ
- 公開・送信・金銭・削除: 対象ごとの承認を確認
- 秘密情報と顧客データを公開Gitやログに出さない
- 完了: テスト・実画面・保存結果を確認し未完を報告
```
