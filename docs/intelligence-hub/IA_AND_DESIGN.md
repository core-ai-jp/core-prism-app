# Information architecture and design

Audience: SME owners first; implementation detail in expandable sections for technical staff. Outcome: choose one workflow, define approval and verification, receive practical worksheets.

Compared directions: (1) editorial white knowledge library, (2) dark product console, (3) workshop workbook. Select (1) for public reading and (3) for tools. Avoid a console metaphor for anonymous readers. Main headline selected over a technical harness headline because it introduces business outcomes before implementation vocabulary.

Existing corporate typography and blue accent are retained. Project surface white, ink #18212b, supporting text #52606e, accessible blue #09658a, paper #f3f6fb. These are project-specific light-surface adaptations, not a global brand change. Reference patterns: corporate source separates copy from layout; theme separates foreground/background contrast; official OpenAI and Anthropic editorial sources provide clear reading hierarchy. No competitor assets or copy reused. Rendered external aesthetic comparison remains pending.

Routes: /insights with six articles; /resources with three kits and security self-check; /resources/confirm for verification/withdrawal. Existing /corp/academy and /roai-score remain links, not duplicated products. Header/footer are shared within Hub. Existing corporate header integration will be a narrow reviewed change.

Viewport gates: 1440,1280,768,390,375. Keyboard focus, 44px interaction targets, explicit form labels, no mandatory marketing consent, reduced motion. PDF reading guide is portrait rather than slide-deck format.
