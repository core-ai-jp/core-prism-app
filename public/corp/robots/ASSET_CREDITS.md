# CORE Sorter 01 — concept scene assets

- `sorter-01-v2.glb` and the concept JPEGs: original procedural geometry created for CORE Robots. The editable Blender source is reproduced by `scripts/robots/build_sorter_asset.py`. The scene is an explanatory concept, not manufacturer CAD, a physical simulation or evidence of an operating machine.
- `studio-small-09-1k.hdr`: **Studio Small 09**, Sergej Majboroda / Poly Haven, CC0. Source: https://polyhaven.com/a/studio_small_09 ; license: https://polyhaven.com/license . Used as a reflection and lighting environment.
- `draco/draco_decoder.wasm` and `draco/draco_wasm_wrapper.js`: Google Draco decoder, Apache License 2.0. The license is retained in `draco/LICENSE`. Runtime files are the versions distributed with the project's Three.js package.
