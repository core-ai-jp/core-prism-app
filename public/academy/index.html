AI AGENT ROADMAP

日本語で指示し、AIに業務を任せる力へ。

非エンジニアも基礎から学べます。単に回答を得るだけでなく、作業手順・ツール連携・権限制御を整え、定型業務をAIエージェントに委ねる方法を実践します。必要な環境構築は講師が支援します。

ChatGPT

質問・要約・文章作成・調査・企画・資料の下書き。まず日本語で仕事を依頼する基礎を学びます。

Claude / Claude Code

PC上のファイルとフォルダを扱う演習、共通指示ファイル、Skillsの作成、MCP連携、検証手順を学びます。

Gemini

情報の整理と比較、調査、Google系サービスを使った作業の連携方法と確認ポイントを学びます。

各社ロゴはそれぞれの商標です。各機能の利用可否は契約プラン・利用環境によって異なります。各社との提携を示すものではありません。

ハーネスとは？

AIが仕事を繰り返し安全に進めるための「実行環境と運用ルール」の総称です。仕事の手順を定めるSkills、指示ファイル、必要な資料を置くフォルダ、MCP等のツール接続、承認範囲、ログ、テストを組み合わせます。設定しただけで無制限に自動化できるわけではありません。

THE GOAL

AIに任せられる仕事を、自分の手で一つ完成させる。

例：商談前の会社調査 → 質問案作成 → 議事録整理 → 提案書ドラフト → 担当者の確認。経理なら資料の整理から月次レポート下書きまで。最終送信・決裁・重要な変更は人が承認します。
